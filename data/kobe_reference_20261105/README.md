# 神戸港の保存済み参照値

実験では、集計結果を小数第3位に丸めた3.186時間を `main.py` の固定値として使う。参照値は2026年11月25日に、収集終了までの入港船予定表を使って更新した。

| 項目 | 値 |
| --- | --- |
| 取得日 | 2026年10月23日〜11月21日（30日、欠けた日なし） |
| 翌日予定の対象日 | 2026年10月24日〜11月22日 |
| 対象船席 | PC-14・PC-15(E)・PC-16・PC-17 |
| 翌日予定件数の合計 | 226件 |
| 1日平均予定件数 | 226 ÷ 30 ≈ 7.533件 |
| 基準平均間隔 | 24 × 30 ÷ 226 ≈ 3.186時間 |

各取得日の最後の入港船予定表から、翌日の対象船席への予定だけを抽出した。同じ表では「コールサイン（空欄なら船名）と予定日」が同じ行を1件と数えた。予定件数は到着規模の目安に使い、実際の寄港数・到着分布・荷役時間・待ち時間の推定には用いない。

| ファイル | 保管内容 |
| --- | --- |
| [kobe_reference.json](kobe_reference.json) | 集計方法・期間・平均間隔・参照原本30件の名前とSHA-256 |
| [kobe_daily_forecasts.csv](kobe_daily_forecasts.csv) | 日ごとの翌日予定件数 |
| [kobe_reference_rows.csv](kobe_reference_rows.csv) | 対象行・原本の行番号・集計への採否 |
| `source_csvs.zip` | 10月23日〜11月4日の原本13件。ローカル保管 |

旧13日分はZIP内の原本から日別件数と対象行を再現し、既存の記録と一致した。11月5日〜21日の原本は収集用リポジトリにあり、JSONには取得元のコミット・パス・SHA-256を記録した。

## 収集終了

日本時間11月21日11時56分に最終収集が完了した。5種類のCSVが保存され、取得失敗は0件だった。神戸西・六甲東の航路情報は工事中のため対象外だった。11月25日に収集用ワークフローを削除し、リポジトリとCSV履歴を保全した。[最終収集記録](https://github.com/ryusuke2003/kobe-port-collector/blob/codex/kobe-port-data/data/kobe_port/last_collection.json)・[削除コミット](https://github.com/ryusuke2003/kobe-port-collector/commit/c4498f7ffbe0f6400fc5cfd707d4f95a28bd9c8a)
