# 港湾システム停止・手動切替とバース運用の先行研究

調査日：2026年11月17日。今回の重点は「TOS停止時の限定的な能力の下での手動運用方式の比較」。停止なしと復旧待ちを基準にする。[研究設計](研究設計.md)と[背景](研究背景.md)に対応する。準備2時間・同時上限2隻の実験を10試行で実施済み。一般の再計画・復旧、代替要員の投入判断、FIFOや短時間優先は既存の考え方であり、新規アルゴリズムや未研究分野の発見は主張しない。

## 1. 調査範囲

検索語は berth allocation under disruption、berth allocation recovery、berth rescheduling、manual fallback operations in ports、port business continuity、port cyber resilience、queueing backup server activation setup time、港湾 TOS システム障害 マニュアル 荷役 切替 BCP。出版社・著者所属大学・会議公式サイトと公的資料を優先した。検索結果の全件を系統的に収集したレビューではなく、同一研究の不存在は証明しない。

全文を確認できた資料と、公式要旨・検索索引の一部だけ確認できた資料を表で区別する。出版社の403、公開PDFの取得容量制限等があり、要旨だけから「その要素を扱っていない」と断定しない。特に2026年のプレプリントは掲載論文と区別する。

## 2. 本研究で参照する論文

### Imai, Nishimura, Papadimitriou（2001）

*The dynamic berth allocation problem for a container port*. [DOI](https://doi.org/10.1016/S0191-2615(99)00057-0)。目的は公共バースの動的な船・バース・順番の割当。整数計画とラグランジュ緩和による方法を比較する。実験は乱数生成問題で、到着間隔は指数、荷役時間は2次アーラン分布。良い解を小さい計算負担で求めることを評価する。最適性や現代のKICTへの適合を与える資料ではない。現行実装の離散型と分布族の参考にする。平均4.8時間は本研究の仮定であり、同論文や神戸港の実測値ではない。荷役は全バースで共通とする。

### Umang, Bierlaire, Erera（2013年報告／2017年掲載）

*Real-time management of berth allocation with stochastic arrival and handling times*. [大学公開技術報告](https://transp-or.epfl.ch/documents/technicalReports/NitBierEra2013.pdf)、[掲載版DOI](https://doi.org/10.1007/s10951-016-0480-2)。本文を確認したのは2013年版。目的は不確実な到着・荷役の下で基準計画を実時間に回復すること。貪欲法、Smart Greedy、最適化方式を比較。Saqrのバルク港を背景にした確率モデルで、混雑・不確実性等を変えて評価する。最適化方式の費用面の優位と計算負担、Smart Greedyの計画維持面の利点を報告する。実行途中に得る情報の扱いを参考にするが、同方式の再実装ではない。本研究は荷役見積り誤差を入れず、TOS停止中の新規開始を準備時間と同時上限で制限する。

### Hacks, Pahl（2024）

*Cyber Security Assessment of An Interoperable Port Call and Voyage Optimization tool*. [DOI](https://doi.org/10.1088/1742-6596/2867/1/012047)、[大学公開本文](https://findresearcher.sdu.dk/ws/portalfiles/portal/276248091/cyper_Security.pdf)。目的は港湾・航海の情報連携に対する脅威評価。harborLangとYACRAFで資産・侵入経路・影響・防御を結び付ける。仮想の三港連携にETA・ETD改ざんを例示。実事件の再現や船別待ちの実測ではなく、手法の評価・拡張を残す。本研究の停止モデルや誤差分布の根拠にはしない。

### König, Rass, Schauer（2019）

*Cyber-attack impact estimation for a port*. [DOI](https://doi.org/10.15480/882.2496)、[公開PDF](https://www.econstor.eu/bitstream/10419/209392/1/hicl-2019-28-164.pdf)。公開サイトにアクセス制限があるため保存原文を参照。目的はNotPetyaを背景とした影響の波及評価と対策箇所の把握。サイバー・物理資産を依存ネットワークと確率的Mealyオートマトンで表す。仮想のコンテナ引取業務で港内部と外部提供者への攻撃例を比較し、外部依存も重要とする。掲載例は各1実行で、確率の実測校正も課題。本研究ではこの波及モデルを再現せず、情報機能の制約と、開始済みの物理荷役の継続を分ける考え方を使う。

### Weaver, Marla（2018）

*Cyber-Physical Simulation and Optimal Mitigation for Shipping Port Operations*. Winter Simulation Conference。[会議原文](https://www.informs-sim.org/wsc18papers/includes/files/242.pdf)、[DOI 10.1109/WSC.2018.8632551](https://doi.org/10.1109/WSC.2018.8632551)。目的はサイバー・物理障害による物流影響と対策費用を評価すること。貨物流動シミュレーションと費用を抑える最適化を接続する。遅延として障害を表す例で、資産・機能の影響を評価する。データの完全性を損なうすべての攻撃を遅延で表せるわけではないと明記。本研究の「停止後に運用対策を比較する」発想は既存であり、新規と主張しない。本研究では手動継続の準備時間と同時処理能力を集約し、2時間・2隻に固定して選船順を比較する。記録作業は追加遅延として扱わない。

### Kim, Park, Park, Cho（2021）

*Rescheduling Strategy for Berth Planning in Container Terminals: An Empirical Study from Korea*. [出版社本文・DOI 10.3390/jmse9050527](https://www.mdpi.com/2077-1312/9/5/527)。目的は到着情報更新によるバース・岸壁クレーン再計画。混合整数計画とローリングホライズンを使い、釜山のターミナルの実データによる3シナリオで、担当者の計画より罰金費用・出港遅延を抑える結果を示す。クレーンや連続的な着岸位置を含み、今回の簡略モデルと同じではない。実港データのある再計画研究との検証水準の違いを明記する。

### van der Steeg, Oudshoorn, Yorke-Smith（2023、オンライン2022）

*Berth planning and real-time disruption recovery: a simulation study for a tidal port*. [出版社本文・DOI 10.1007/s10696-022-09473-8](https://link.springer.com/article/10.1007/s10696-022-09473-8)。目的は港拡張の評価に用いる初期計画と実時間回復。潮汐・周期到着・喫水を考慮した制約プログラミングと段階的ヒューリスティクスを高精度シミュレータに接続する。欧州河川港の事例で、混雑が増すほど初期計画の余裕が重要とする。事例の混雑閾値を今回へ転用しない。再計画と混雑の評価自体は既存であり、本研究は同じ手動能力の下で順序を変え、平均待ちと長時間船の負担を比べる。

### Dávila de León, Lalla-Ruiz, Melián-Batista（2022）

*Disruption Management Approaches for Berth Scheduling in Bulk Terminals*. [出版社本文・DOI 10.1155/2022/8069796](https://onlinelibrary.wiley.com/doi/10.1155/2022/8069796)。目的は到着・荷役の不確実性への事前準備と反応的調整。港を背景とする確率入力で、バッファの有無と事前・事後を組み合わせた方式を評価し、組合せの有効性を報告する。今回の「復旧後に調整する」だけでは差別化にならない。本研究では利用不能な情報機能を背景に、手動の準備・能力を仮定して比較する。同論文の港の実測値を転用しない。

### Chakravarthy, Agnihothri（2008）

*A server backup model with Markovian arrivals and phase type services*. *European Journal of Operational Research*, 184(2), 584–609。[DOI](https://doi.org/10.1016/j.ejor.2006.12.016)、[著者所属大学の要旨](https://digitalcommons.kettering.edu/industrialmanuf_eng_facultypubs/41/)、[出版社](https://www.sciencedirect.com/science/article/abs/pii/S0377221706012276)。待ち人数に応じて代替要員を呼び、応援到着までの遅れと固定・変動費用を考慮し、投入・解除の閾値を評価する研究。主処理者に応援を加える定常モデルであり、TOS停止時に主処理を代替する今回のモデルとは異なる。数式の再実装や、港湾の閾値の転用はしない。切替の便益と負担を同時に測る必要性を考える基礎文献とする。

### Rabadi, Pinto, Talley, Arnaout（2013）

*Port recovery from security incidents: A simulation approach*. *Risk Management in Port Operations, Logistics and Supply-Chain Security*, pp.83–94。[所属大学の書誌・要旨](https://researchconnect.suny.edu/en/publications/port-recovery-from-security-incidents-a-simulation-approach/)。米国のターミナルで、船・トラック・鉄道と荷役資源を含むモデルを用いて、検査遅延やゲート減少等からの回復と戦略判断を検討する。確認できたのは要旨であり、具体的な比較結果や手動処理の条件は未確認。港湾の復旧時間をシミュレーションで評価すること自体を本研究の新規性にはしない。

### Senarak（2025）

*Leveraging advanced technologies and strategies for port cyber resilience: Strengthening incident response and recovery*. *Transportation Research Interdisciplinary Perspectives*, 34, 101666。[出版社・DOI](https://doi.org/10.1016/j.trip.2025.101666)、[出版社の論文ページ](https://www.sciencedirect.com/science/article/pii/S2590198225003458)。Laem Chabang港を対象に、デルファイ法による専門家の合意から、対応・復旧業務と実施上の課題を整理する。確認範囲は要旨・ハイライトで、全文の検討は残る。港湾の対応手順の根拠を探す優先候補であり、船の待ち時間を改善したという実験の根拠としては使わない。

### Ávalos-Ochoa, Sánchez-Lara, Arriaga-Navarro（2026、プレプリント）

*A Framework for Characterizing and Guiding Service Level Recovery in Port Interfaces Following Cyberattacks*. Research Square、2026年5月20日公開、[DOI 10.21203/rs.3.rs-9582637/v1](https://doi.org/10.21203/rs.3.rs-9582637/v1)、[公開元PDF](https://assets-eu.researchsquare.com/files/rs-9582637/v1/d9dc3780-6832-4d5c-8df0-d71c16bc0583.pdf?c=1779435429)。メキシコの港湾関係者8名を含むワークショップ等に基づき、可用性・信頼性・ガバナンスから段階的な回復を捉える枠組みを提案する。公開元の検索索引で要旨・4.1節等を確認したが、大容量PDFの全文取得はできていない。通常復帰を機器の復旧だけで捉えない近接研究として挙げる。査読済みの成果や定量的な切替効果の検証とは扱わない。

## 3. 重複する点と残る検討

港湾の障害からの回復、情報機能の障害による物流遅延、代替要員の呼出しと投入費用、サービス水準の回復は既存研究と重なる。「手動に切り替えると待ちが減る」「システム復旧と業務回復は違う」だけを新規性にしない。

今回の貢献候補は、限定的な手動継続を準備時間と同時運用上限で表し、同じ条件で手動FIFOと短い荷役優先を比べ、平均待ちと長時間船の負担を示すこと。神戸港の保存済み予定規模を到着生成の参考にする。ただし、この組合せの学術的新規性は未確定である。2つの手動手順が実港で使われていることを確認したわけではなく、手作業で説明できる比較用のルールとして提案している。

Umangらが説明するFIFOは計画順を維持する比較であり、今回使う実到着順FIFOと同一ではない。短時間優先の既知の順序付け結果を、動的な到着・複数バース・一時的能力低下を持つ今回の条件へそのまま転用しない。停止時間の閾値や方式の逆転が必ず見つかるとも置かない。

次の確認は、Senarakの全文、港湾の手動継続・通常復帰の具体的手順、切替準備と確認件数の計測である。準備2時間・同時上限2隻は固定した仮定で、その変更への頑健さは未検証として、実港での最適な切替時刻や人員数は断定しない。同時上限Kで情報確認の困難さを表す妥当性は、計算が動いたことだけでは実証されない。現場の工程や保持情報との対応付けが残る。

## 4. 保存している補助資料

手動継続の実例・公的指針は[研究背景](研究背景.md)の表1にまとめた。特に国交省の安全ガイドライン第3版（2026）のセキュリティ責任者編1.8.2、PEMA（2025）6節、NIST SP800-34 Rev.1の4.2.1節・代替処理手順を参照する。指針の存在と、定量モデルの妥当性は分けて判断する。

原論文の保存先と書誌情報は[資料の入手元](../先行研究/資料の入手元.md)にまとめる。原文PDFは削除しない。

ENISA（2019）の *Port Cybersecurity — Good practices for cybersecurity in the maritime sector* は、港の関係者・情報システム・脅威・対策を整理した公的報告である。[DOI](https://doi.org/10.2824/328515)。第2.3〜2.4節は情報連携、第4.3節Scenario CはPCSのデータ改ざん、第5節は対策の参考になる。システム停止時のバース別手順や、今回の待ち時間の実測根拠とはしない。

Mubder（2024）の *The implementation of berth allocation policies that enable Just-in-Time arrival in port calls* は、Gävle港での予約制と情報共有の実装を扱う事例研究。[DOI](https://doi.org/10.1108/IJPDLM-11-2023-0442)。第3節の調査方法と第6〜7節の議論・結論を読む。組織間の協力や他資源への依存を理解する参考とし、今回の到着順ルールを予約制度全体と同一視しない。
