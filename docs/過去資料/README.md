## 11月5日の旧実験を検算する

11月5日の旧検算スクリプトはCSVと当時のコードのSHA-256を照合するため、実験時のコミット`9cd41aa`を展開して使う。現在の実験には参照CSV原本の復元は不要である。

このMacのリポジトリ直下で、保管用ZIPから参照原本13件を復元し、コードと結果を一時フォルダへ展開する。ZIPはローカル保管で、別PCへ移す際は別途コピーが必要。検算で作る`validation.json`も一時フォルダ内へ保存する。

```bash
unzip -n data/kobe_reference_20261105/source_csvs.zip -d data/kobe_port/raw
audit_dir=$(mktemp -d /tmp/thesis-audit-20261105.XXXXXX)
git archive 9cd41aa simulation.py main.py port_collection/analyze_port_data.py results/final_20261105 | tar -x -C "$audit_dir"
.venv/bin/python "$audit_dir/results/final_20261105/audit_results.py"
```
