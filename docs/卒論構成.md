# 手動運用方式を比較する卒業論文の構成

仮題：コンテナターミナルのTOS停止時における手動運用方式と処理能力が船舶待ちに与える影響。

[研究設計](研究設計.md)に対応する章立て。主実験・補助実験は各10試行を実施済み。[結果と考察](実験結果と考察.md)の平均改善と長時間船の負担を中心に記述する。

表1 各章の構成

| 章 | 書くこと | 根拠・準備 |
| --- | --- | --- |
| 1 背景 | TOS停止と限定的な手動継続。実事件・訓練・仮定の区別 | [研究背景](研究背景.md) |
| 2 目的 | 同じ能力で到着順を守るか、短い荷役を優先するか。平均と長時間船の負担を比較 | [研究設計](研究設計.md) |
| 3 先行研究 | 港湾回復・情報障害の物流影響・代替処理・順序付け。既存の考え方と貢献候補 | [文献レビュー](先行研究の整理.md) |
| 4 データとモデル | 神戸港の予定件数、4バース、到着・荷役の仮定、準備時間と同時運用上限 | [研究設計](研究設計.md)・[モデル仕様](モデル仕様.md) |
| 5 実験設計と検証 | 同じ10入力の共有。主実験260・補助400、共通80の再利用。手計算・境界対照 | [実装説明](実装説明.md)・[テスト](../test_simulation.py) |
| 6 結果 | 主実験の平均待ちと対応差、長時間船・最大待ち。補助実験の準備・能力への依存 | [実験結果と考察](実験結果と考察.md)・[Excel](../results/実験結果.xlsx) |
| 7 考察 | 平均改善と長時間船の負担、能力確保と順序変更の違い、短い停止で差が小さい条件 | 24時間停止・2倍頻度の具体例を中心に、主実験と補助を接続 |
| 8 限界と結論 | Kの集約仮定、荷役見積り既知、予定規模と実績の区別、人的負担・復帰作業の未評価 | 実港の最適方式・必要人員へ広げない |

結論は「短い荷役優先を常に採用すべき」ではなく、全船平均の改善と長時間船の負担の両方を判断する必要がある、という条件付きの知見にする。停止なしもFIFOで最適解ではないため、停止なしとの差を純粋な停止被害と呼ばない。

残る作業は、港の手動継続手順・荷役見積りの保持方法とモデルの対応を確認すること、先行研究の全文未確認箇所を詰めること、結果を卒論本文へ書くこと。準備時間・Kに実測根拠が得られなければ仮定の感度分析として扱う。長待ち救済や切替費用は今後の課題とし、今回の条件へ新しい係数や複雑な最適化を追加しない。
