# 到着予定情報の改ざんとバース割当

船舶の申告到着時刻が改ざんされたときの影響を、正常時とのシミュレーションで比較します。
既存のバース割当・再割当の考え方を、限定した到着情報改ざんの攻撃モデルに適用し、被害と軽減の条件を評価する研究として位置づけています。
Pythonの関数と繰り返し処理を中心に、卒論で説明できる規模で実装しています。
1週間のデータを生成し、固定計画・同じバース内の調整・バース変更ありの3ルールを比較できます。初期値は各設定10試行です。改ざん対象はV5に固定しています。
各条件の全船の計画を運用開始前に1回作り、ルール間で共有します。調整ルールでは、到着済みの船の中で、その条件の計画順を優先します。荷役時間は運用者が事前に正確に知る前提です。
平均到着間隔2.37時間・3バースは暫定値で、正常時の待ち時間が原則0になる条件の調整はこれからです。荷物の位置に基づく距離係数も未実装です。教授の指摘、実装済みの部分、未決定事項は[今後の計画](docs/今後の計画.md)に記録しています。

## 実行方法

Python 3.10以上を使用します。既存の`.venv`があれば作成・インストールは省略できます。

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

| 引数 | 初期値 | 意味 |
| --- | --- | --- |
| `--trials` | 10 | 各設定の試行回数。同じ試行の元データを全条件で共有 |
| `--duration` | 168時間 | 到着を生成する期間。期間終了後も対象船の荷役を完了する |
| `--ships` | 指定なし | 指定時は期間の代わりに固定隻数を使う。V5を含める必要がある |
| `--berths` | 3 | バース数 |
| `--interval` | 2.37時間 | 指数分布の平均到着間隔。正常時が原則0になる値は未決定 |
| `--policy` | all | `all`で3ルール。`fixed`・`same_berth`・`reassign`で個別指定 |
| `--seed` | 42 | 最初のseed。試行ごとに1増やす |
| `--shift` | 4.0 | 申告を早める・遅らせる時間の大きさ |
| `--output` | results_new | 新しい比較の保存先 |
| `--no-plot` | 指定なし | グラフを作らない |
| `--no-save` | 指定なし | ファイルを保存せず、ターミナルに結果だけ表示 |

```bash
# ファイルを保存せず結果だけ確認する
python main.py --no-save

# 保存済みの結果を残し、別の条件を試す
python main.py --shift 2 --output results_shift2

# 1試行だけ確認し、グラフを省略する
python main.py --trials 1 --no-plot --output results_single

# 到着間隔・バース数を変えて比較する（数値は設定例）
python main.py --interval 4 --berths 4 --output results_interval4

# 保存済み100試行と同じ固定隻数・固定計画の条件を使う
python main.py --ships 10 --policy fixed --trials 100 --output results_fixed_reproduction

# 自動テスト
python -m unittest -v
```

同じ保存先の同名ファイルは上書きします。`--no-plot`では古いグラフも削除します。
`--no-save`では保存先の作成・CSV/JSON/PNGの保存・古いグラフの削除を行いません。`--output`を一緒に指定しても保存しません。
船数の増加だけで混雑が強くなるとは限りません。混雑度を変える実験は[今後の計画](docs/今後の計画.md)を参照してください。
`--ships`と`--duration`は同時に指定できません。期間内の隻数が少なくV5が存在しない場合は、試行を再生成せず設定エラーにします。

## モデルの概要

船ごとに基準荷役時間を作り、バース係数だけで補正します。荷役時間は「基準荷役時間 × バース係数」で、noiseは加えません。
3バースの係数0.9・1.0・1.1は船ごとに並べ替え、相性を表します。
正常・早い申告・遅い申告と全ルールは、同じ試行の実到着と荷役時間を共有します。

計画は申告時刻順のFCFSで作り、次のルールで実行します。

| ルール | バースと順番 | 計画より早い開始 |
| --- | --- | --- |
| `fixed` | 計画バース・バース内の順番を維持し、未到着船を待つ | 許さない |
| `same_berth` | 計画バースを維持し、到着済みの船を計画順で選ぶ | 許す |
| `reassign` | 到着済みの船を計画順で選び、その船の荷役時間が最短の空きバースを使う | 許す |

到着間隔を順に足して、週内に実到着する船を生成します。週単位ではV1も最初の到着間隔の後に到着し、固定隻数では従来どおりV1が時刻0に到着します。全バース空きから始める初期状態は仮設定です。
荷役中の船は移動・中断しません。待ち時間は実到着から荷役開始まで測り、正常時の待ち時間もそのまま記録します。
分布・選択規則・評価式の詳細は[計算の実装説明](docs/実装説明.md)にまとめています。

## 出力と結果の確認

新しい実験の初期保存先は`results_new/`です。`results/`は追加前に実行した、固定隻数・固定計画100試行の記録です。船ごとにバース係数を並べ替え、基準荷役時間×バース係数で計算しています。
条件・数値・検証は[予備比較レポート](docs/予備比較レポート.md)を参照してください。
noiseありの旧データは`results/archive/20261007_noiseあり/`に保管しています。
旧固定係数方式のデータは`results/archive/20261006_固定係数/`に保管しています。

| ファイル | 内容・読む順序 |
| --- | --- |
| `config.json` | 最初に確認する実験条件、seed、方式、ライブラリの版 |
| `summary.csv` | ルール・条件別の平均と標本標準偏差 |
| `paired_comparison.csv` | 同じルール・試行の正常時との差、増減回数、固定計画に対する平均軽減量 |
| `plans.csv` | 正常・各攻撃条件の運用前の全船の計画。ルール間で共有 |
| `schedules.csv` | 試行・条件・ルール・船番号で絞って調べる計画と実行。計画バースと実行バースを記録 |
| `ship_data.csv` | 元データ、船ごとの係数配置、バース別荷役時間 |
| `run_metrics.csv` | 試行・条件・ルール別の8指標、隻数、待ち時間が出た隻数 |
| `waiting_time_comparison.png` | 全船と対象船以外の平均待ち時間を、条件・ルールで比較 |

CSVはUTF-8 BOM付き、単位は時間です。`normal`は正常、`early`は早い申告、`late`は遅い申告です。
差は「攻撃時 − 正常時」で、正なら悪化を表します。±0.000000001時間以内は変化なしとします。
軽減量は「固定計画の攻撃影響 − 調整ルールの攻撃影響」で、正なら軽減を表します。各ルール自身の正常値を引いてから比較します。
週内の隻数が異なる場合も、まず各試行の船平均を求め、その値を試行間で平均します。
1試行では標本標準偏差が定義できず、該当欄は空欄です。

## 神戸港の公開資料と仮定の区別

2026年10月6日に、神戸市の[神戸港の統計（年報）](https://www.city.kobe.lg.jp/a49918/tokei/annualreports.html)を確認しました。
入港隻数、貨物量、コンテナ個数、港湾施設などの集計が掲載されています。
[2024年の港湾統計の速報資料](https://www.city.kobe.lg.jp/documents/58977/2024kousei.pdf)では、外内貿コンテナ取扱個数は約277万TEUとされています。
この速報値は港全体の集計であり、保存済みの10隻・3バースや、新しい週単位のモデルを直接表す値ではありません。

確認した資料からは個別船の荷役開始・終了時刻の組を得ていません。
そのため、平均到着間隔2.37時間、平均基準荷役時間4.8時間、バース係数、攻撃幅は実測から推定した値として扱いません。
この実験は仮定した条件下で改ざんの影響を調べるためのものです。

分布の実装は [NumPyの `Generator.gamma` の説明](https://numpy.org/doc/stable/reference/random/generated/numpy.random.Generator.gamma.html)、Erlang分布との関係は [SciPyのErlang分布の説明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.erlang.html)を参照しています。
