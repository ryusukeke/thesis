# 到着予定情報の改ざんとバース運用

船は元の実到着時刻で来る一方、港側が改ざんされた申告を信じて全船計画を更新する状況を調べます。離散型4バースを、固定・同じバース内調整・バース変更の3方式で運用し、同じ入力・方式の正常時からの増減を比較します。調整2方式の前倒し時間に上限はありません。

現在は複数船版`discrete_4berth_multi_ship_v5`です。1隻・10%・30%・50%を対象にした主実験と、10%・30%・50%の早い・遅い申告が混在する補足を、各条件100試行で実行しました。最新の設定・2CSV・7図のPNG/PDFは`results/`直下に保存します。これは仮定条件での影響評価であり、神戸港の実待ち時間による検証ではありません。

固定方式では改ざん規模に応じて追加待ちが大きくなる条件があり、同じバース内調整は平均では軽減しましたが、悪化するケースもありました。バース変更の全船平均への追加影響は小さくても、船ごとの負担は変わります。数値の比較は[結果](docs/予備比較レポート.md#4-規模方向方式の比較)、規則と結び付けた解釈は[考察と限界](docs/予備比較レポート.md#8-結果の範囲と検証)を参照してください。

## 実行

既存の`.venv`を使用できます。新規環境はPython 3.10以上で`requirements.txt`をインストールします。

```bash
# 複数船の主実験と混在補足を各条件100試行で再現
.venv/bin/python main.py --study --output results/reproduction_multi

# 少数試行の確認。既存結果とは別の保存先へ
.venv/bin/python main.py --study --trials 1 --output /tmp/thesis_multi_check

# 手計算・物理制約・再現性などの確認
.venv/bin/python -m unittest -v
```

| 引数 | 扱い |
| --- | --- |
| `--study` | 複数船の主実験・混在補足。省略時は確認用のV5・±4時間の単一設定 |
| `--trials` / `--seed` | 既定100試行、最初のseed42。各試行で1ずつ増加 |
| `--output` | 既定は`results/`直下。直下にファイルがあれば上書きせず停止 |
| `--no-plot` / `--no-save` | 描画だけ省略／保存・描画・保存先作成を省略 |

実験のバース数4、到着生成期間168時間、通常変更幅4時間、3方式は`simulation.py`で定義します。主実験は需要0.75・1・1.5倍、規模1隻・10%・30%・50%、幅2・4・8時間です。到着間隔の基準は保存済みJSONの`24×13÷103=3.029126213592233`時間。参照JSONがなければ停止し、別の仮定値へ切り替えません。

各図はPNG/PDFの2形式です。通常の単一設定は図5〜7の3図。船別詳細CSV、参照データやソースコードのコピーは保存しません。主実験では1入力ずつ運用を集計し、図用の1試行だけ船別運用を残します。検証時だけ計算APIの`keep_schedules=True`で全運用を保持できます。

CSVはUTF-8 BOM付き、時間単位は時間です。`attack_scale`は`single/p10/p30/p50`、`scenario`は`normal/early/late/mixed`。`experiment_group`は正常参照`baseline`、主実験`main`、混在補足`mixed_supplement`です。`target_ships`と`report_shifts`はJSON形式で、後者は0で丸めた後の実際の変更量です。

正常値の対応キーは需要・試行・規模・方式です。正常運用は900回で、対象群の区別のため正常指標を3,600行記録します。改ざんは主21,600＋混在8,100＝29,700運用。同じ入力・対象集合を繰り返すので、運用数を独立標本数とは数えません。

`summary.csv`の`mean`は改ざん時の平均、`normal_mean`は正常平均、`mean_difference`は対応差、`mean_mitigation_vs_fixed`は固定の対応差からの軽減量です。図1〜3の点は対応差の平均、上側のひげは対応差の標本標準偏差1個分で、信頼区間ではありません。1試行の標準偏差はCSVでは空欄、図ではひげを描きません。0の正常差は待ち0を意味しません。

## モデルと結果の扱い

到着間隔は指数分布、基準荷役時間はガンマ分布shape2・scale2.4・平均4.8時間、荷物の最寄りバースは一様乱数という仮定です。バース別荷役時間は基準時間×`(1+0.1×最寄りとの番号差)`。予定件数は規模の参考で、分布や荷役時間を実測へ当てはめたものではありません。

対象選択は別乱数の順列の先頭を取り、割合の端数は切り上げます。小さい群を大きい群に含め、対象集合を幅・方向・方式間で共有します。混在は選択順に符号を交互に割り当て、最初の符号だけ乱数で決めます。1隻の混在は重複するので計算しません。旧位置別の1隻結果とは対象の選び方が違います。

全船が全バースを使い、荷役時間を正確に知り、調整に準備時間を要しないという簡略化があります。実到着前の開始、荷役重複、開始後の中断・移動は認めません。船長・水深・クレーン・天候・航行速度は計算せず、最適解や実港の完全防御は主張しません。

位置別1隻版の100試行は`results/archive/20261111_実到着固定_1隻_100試行/`、到着調整ありの旧100試行やそれ以前の結果も[過去資料](docs/過去資料/README.md)から参照できます。現在の結果と混ぜず一式で保持します。コード履歴はGitで管理します。
