# TOS停止時の手動運用と船舶待ち時間

TOS（ターミナル・オペレーティング・システム）が一定期間使えないとき、準備後に限られた能力で継続する**手動FIFO**と**短い荷役を優先する方式**を比較します。停止なし・復旧待ちを基準に置き、全船平均待ちと長時間荷役船の負担を調べます。

離散型4バースの仮想ターミナルです。停止中も開始済みの荷役は続け、新しい荷役開始だけを制限します。通常と復旧後は4バースのFIFOへ戻します。到着申告の改ざん、予定との到着誤差、保存計画の再計算は扱いません。

神戸港の保存済み翌日予定件数から船の生成頻度の規模を設定しています。到着・荷役の分布、準備時間、手動能力は仮定です。名古屋港事案やKICTの実運用を再現した結果ではありません。

## 実行方法

Python 3.10以上。既存の `.venv` と `requirements.txt` を使います。新しい依存ライブラリは追加していません。

```bash
# 依存の準備が必要な場合
.venv/bin/python -m pip install -r requirements.txt

# 両実験を10試行で再現。保存済み結果を保護するため空の別保存先へ
.venv/bin/python main.py --output /tmp/手動運用の再現

# 主実験だけ／補助実験だけ
.venv/bin/python main.py --experiment 主実験 --output /tmp/手動運用の主実験
.venv/bin/python main.py --experiment 補助実験 --output /tmp/手動運用の補助実験

# 少数試行の動作確認
.venv/bin/python main.py --trials 2 --output /tmp/手動運用の確認

# 自動テスト
.venv/bin/python -m unittest -v
```

表2 コマンド引数

| 引数 | 既定 | 意味 |
| --- | --- | --- |
| `--experiment` | 両方 | 両方・主実験・補助実験から選ぶ |
| `--trials` | 10 | 試行数。動作確認では減らせる |
| `--output` | results | 空の保存先。既存ファイルを上書きしない |

保存済みの `results/` がある状態で引数なしで実行すると、上書きを防いで終了します。シード等の共通条件は [main.py](main.py) の `make_settings()`、比較する停止時間・準備時間・手動上限は [simulation.py](simulation.py) の `build_conditions()` にまとめています。`--seed` 等の細かい引数は増やしていません。

## 主実験と補助実験

表3 実験の違い

| 項目 | 主実験 | 補助実験 |
| --- | --- | --- |
| 問い | 停止が長いほど、手動方式の差と負担はどう変わるか | 準備時間・手動能力の設定で結論はどう変わるか |
| 停止時間 D | 6・12・24・48時間 | 24時間 |
| 準備時間 s | 2時間 | 0・2・6時間 |
| 手動同時上限 K | 2隻 | 1・2・3隻 |
| 到着頻度 | 基準・2倍 | 主実験と同じ |
| 試行 | seed42〜51の10入力 | 同じ10入力 |
| 使用する運用数 | 260 | 240 |

計算関数は共通です。補助実験は準備時間・手動同時上限をそれぞれ一つずつ変更する5組（s,K）=(0,2),(2,1),(2,2),(2,3),(6,2)に限定します。両方を実行すると共通80運用を再利用し、合計420運用・42条件になります（各条件10試行）。420個の独立標本ではありません。

Excelは次の5シートです。見出し・区分は日本語、時刻は時間単位。数値は丸めず、表示だけ小数3桁にしています。

- **条件別集計**：各試行の指標の平均・標本SD、停止なし比・手動FIFO比の平均待ち増減回数。
- **試行別結果**：再生成済みの420運用。主実験・補助実験の使用欄で絞れます。
- **船別入力**：試行・到着頻度・船につき1行。全条件で共有する到着・荷役・長時間船の区分。
- **船別実行**：全運用の開始・完了・バース・待ち・開始時の状態。
- **代表試行イベント**：試行1だけの判断時刻、開始前後の荷役中隻数、開始数・待機船数。

停止なし・復旧待ちの準備時間や手動上限は該当しないため、識別用に停止なしは s=0,K=4、復旧待ちは s=0,K=0 と記録します。短時間優先と比較するFIFOは同じD,s,Kの条件です。停止なしの停止中到着群、停止なし・復旧待ちのFIFO比較欄等、対象外の指標は空欄です。

図の点と誤差棒は10試行の平均と標本SDで、信頼区間ではありません。図2・6は試行ごとの「短い荷役優先−手動FIFO」の対応差です。補助実験の図4はK=2固定で準備時間、図5はs=2固定で手動上限を比較します。長時間船の平均と悪化船数も読み、全船平均だけで方式を選ばない構成です。
