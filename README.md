# 到着予定情報の改ざんとバース運用

船は元の実到着時刻で来る一方、港側が改ざんされた申告を信じて全船計画を更新する状況を調べます。離散型4バースを、固定・同じバース内調整・バース変更の3方式で運用し、同じ入力・方式の正常時からの増減を比較します。調整2方式の前倒し時間に上限はありません。

現在は`discrete_4berth_multi_ship_v6`です。保存済み参照値の到着間隔を使い、各条件の既定は1試行です。対象位置を区分せず、早い申告・遅い申告・混在を比較します。設定・Excel・6図のPNG/PDFは`results/`直下です。

## 実行

Python 3.10以上で`requirements.txt`をインストールします。Excel出力用にopenpyxlを使用します。

```bash
.venv/bin/python -m pip install -r requirements.txt

# 主実験と混在補足を各条件1試行で再現（一時保存先）
.venv/bin/python main.py --study --output /tmp/thesis_reproduction

# 動作確認は既存結果と別の保存先へ
.venv/bin/python main.py --study --output /tmp/thesis_check

# 手計算・物理制約・再現性・Excel保存の確認
.venv/bin/python -m unittest -v
```

| 引数 | 扱い |
| --- | --- |
| `--study` | 規模・幅・方向の主実験と混在補足。省略時は確認用のV5・±4時間 |
| `--trials` / `--seed` | 既定1試行、seed42。回数を明示した場合だけ複数試行にできる |
| `--output` | 既定`results/`。直下にファイルがあれば上書きせず停止 |
| `--no-plot` / `--no-save` | 描画だけ省略／保存・描画・保存先作成を省略 |

4バース・168時間を固定し、平均到着間隔は参照JSONの`24×13÷103=3.029126213592233`時間です。参照JSONがなければ停止し、別の仮定値へ切り替えません。需要倍率のループ・結果列・比較図はありません。

6図は各PNG/PDFです。図番号・タイトル・実験条件は図の下に置き、パネルごとの見出しは上に残します。通常の単一設定は図4〜6の3図。最新結果は設定・Excel・図の14ファイルで、結果CSVやソースコピーを保存しません。Excelは3シートとも日本語の見出し固定・フィルター付き。「条件別集計」は上段の表1から読み、同じ条件の固定・同じバース内調整・バース変更を続けて比較します。右側3列は正常時の平均待ち、改ざん後の平均待ち、その増減です。増加は＋と赤、減少は−と緑で表示し、条件ごとに背景を交互に変えます。「詳細13指標へ」で下段の表2へ移動でき、元の集計値もすべて残しています。「船別データ」は各条件で共有する改ざん前の入力で、船ごとに試行あたり1行を保存します。到着・荷役完了などの時刻はシミュレーション開始からの経過時間です。数値は数値のまま保存し、時間の単位は時間、実際の対象割合は%表示です。隻数・試行番号・シードなどの整数値はそのまま、小数は有効数字3桁以内で末尾の不要な0を省いて表示します（割合は%に換算して3桁以内）。計算誤差程度の残差（絶対値が10⁻¹²未満）は0と表示します。表示書式だけの変更で、保存する計算値は丸めません。Excel上の編集では再シミュレーションされません。

主実験は4規模×3幅×2方向×3方式＝72運用、混在は3割合×3幅×3方式＝27運用。正常3運用を共有し、合計102運用です。正常指標は4対象群で計算するため12行となり、改ざん99行と合わせて111行。99セル×13指標＝1,287集計行です。

Excelの見出し・方式名・申告条件・評価指標は日本語です。「改ざん対象の規模」は1隻・全船の10%・30%・50%、「申告条件」は正常・早い申告・遅い申告・早い／遅いの混在。「実験区分」は正常比較用・主実験・混在の補足です。「改ざん対象船ID」と「各対象船の申告変更量（時間）」はJSON形式で、船の識別子は変更しません。

正常値の対応キーは試行・規模・方式。下段の詳細では「改ざん時の指標値（試行平均）」と「正常時の指標値（試行平均）」を比べ、「正常時との差（試行平均）」を確認します。「固定方式に対する軽減量（試行平均）」は固定の正常差からの軽減量です。1試行の標準偏差は未定義なので空欄、グラフは点と線です。船ごとの平均待ちと、異なる乱数の試行間平均を区別してください。

## モデルと結果の扱い

到着間隔は指数分布、基準荷役時間はGamma(shape2, scale2.4)、平均4.8時間、最寄りバースは一様乱数という仮定です。バース別荷役時間は基準×`(1+0.1×最寄りとの番号差)`。予定件数は発生規模の参考で、実港の到着分布や荷役への当てはめではありません。

対象は1隻・10%・30%・50%。全船の乱数順列の先頭から選び、割合の端数は切り上げます。小さい群を大きい群に含め、対象集合を幅・方向・方式間で共有します。混在は選択順に符号を交互に割り当て、最初の符号だけ乱数で決めます。序盤・中盤・終盤の位置比較は行いません。

全船が全バースを使え、荷役時間を正確に知り、調整に準備時間が要らない簡略化があります。実到着前の開始、荷役重複、開始後の中断・移動を認めません。今回の1試行から、乱数が変わった場合の傾向や統計的有意差は判断しません。
