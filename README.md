# 到着予定情報の改ざんとバース運用

1隻の申告到着時刻だけが改ざんされたとき、他船へ待ちが広がる条件と、計画変更の許容範囲による軽減効果・限界を比較する学部卒論の研究コードです。離散型4バース、正常時は全船待ち0、関数と繰り返し処理で計算します。

2026年11月5日に、神戸港の予定情報の集計、主実験、補足実験、図表、独立検算まで完了しました。[結果・考察](docs/予備比較レポート.md)から執筆を始められます。これは仮定条件でのシミュレーションで、神戸港の実待ち時間による検証ではありません。

## 実行

既存の`.venv`を使用できます。新規環境ではPython 3.10以上で`requirements.txt`をインストールします。

```bash
# 保存せずに小さい条件を確認
.venv/bin/python main.py --ships 10 --trials 1 --no-save

# 主実験の再実行。既存結果とは別の保存先を指定する
.venv/bin/python main.py --study --output results/reproduction_20261105

# 手計算・物理制約・比較条件・参照データ集計の確認
.venv/bin/python -m unittest -v

# 保存済み主実験の全CSVを独立に検算
.venv/bin/python results/final_20261105/audit_results.py
```

保存先にファイルがある場合は停止します。既存結果を上書きしないため、再実行時は新しい`--output`を使ってください。`--no-save`では保存先作成・保存・グラフ生成をしません。

| 引数 | 既定値・扱い |
| --- | --- |
| `--study` | 主実験全体と前倒し上限0時間の補足実験を実行。省略時はV5・±4時間の単一設定 |
| `--trials` / `--seed` | 10試行、最初のseed42。試行ごとに1増やす |
| `--berths` | 4。主実験は4に固定 |
| `--duration` / `--ships` | 既定は168時間の到着候補。固定隻数との同時指定不可。主実験は168時間 |
| `--interval` | 主実験はKICT翌日予定集計から算出。単一設定では仮定の3.0時間。明示値で変更可 |
| `--shift` | 単一設定の変更幅4時間。主実験は2・4・8時間 |
| `--advance` | 同じバース内調整・バース変更の前倒し上限2時間。主実験は2に固定 |
| `--policy` | `all`または`fixed`・`same_berth`・`reassign`・`unrestricted`。主実験は全方式 |
| `--raw` / `--through` | `data/kobe_port/raw`、CSV取得日上限2026-11-04。主実験の参照集計に使用 |
| `--output` | `results/final_20261105`。保存済みのため再実行は別名を指定 |
| `--no-plot` / `--no-save` | グラフだけ省略／全保存を省略 |

## モデルと主実験

- 乱数で到着候補と基準荷役時間を作り、荷物の最寄りバースを1〜4から一様に選びます。荷役時間は基準時間×`(1+0.1×バース番号の差の絶対値)`。基準時間はガンマ分布shape2、scale2.4で、平均4.8時間の仮定です。
- 到着候補から重複しないバース予約を作り、到着・正常申告を予約開始に合わせます。調整前の候補と調整時間を残します。正常時の待ち0を実行結果から検査します。
- 改ざん後は実到着・荷役時間を動かさず、申告情報で全船の計画を1回更新します。同じ条件の計画は全方式で共通です。
- A固定、B同一バース・前倒し2時間、Cバース変更・前倒し2時間、D自由調整・前倒し無制限を比較します。Dは最適解ではなく、予約による制約を外した比較基準です。
- 到着候補の需要倍率0.75・1・1.5、対象位置10・50・90%、幅±2・4・8時間を、同じ10seedで比較します。30組の正常計画から主実験2,160ケース、補足60ケースを実行します。2,220個の独立した標本という意味ではありません。

調整前の候補の平均間隔は、KICT対象船席の各日最終CSVにある翌日予定を集計した`24×13÷103=3.029126…`時間を基準にします。予定件数であり、実績寄港数・実到着分布・荷役時間を推定した値ではありません。主実験には時間帯分布を直接入れず、候補間隔の分布形は指数分布という仮定を置きます。

CSVはUTF-8 BOM付きで、時間単位は時間です。`experiment_group`は主実験`main`／補足`sensitivity`、`target_position`は到着順10%の`early`／50%の`middle`／90%の`late`です。`scenario`の`early`／`late`は申告を早める／遅らせる意味で、対象位置とは別の列です。

同じ方式・需要・試行・対象位置の正常値を引きます。正常参照は改ざん幅ごとには複製しません。グラフは各セル10試行の平均、上側のひげは標本標準偏差1個分です。1試行の場合の標準偏差は未定義なのでCSVは空欄、図ではひげを描きません。有意差や信頼区間は示しません。

## 解釈の範囲

4バースは[商船三井の2026年8月19日の発表](https://www.mol.co.jp/info/article/2026/0819.html)を参考にしています。一方、全船が全バースを使えること、荷役時間が正確に分かること、前倒し上限、到着調整上限なしは簡略化です。船長・水深・クレーン・天候・実際の航行速度は計算しません。

Dで待ち0になる結果は、同時到着のない正常計画と自由なバース選択というモデル構造に依存します。CでもBやAより悪化した例があり、全体最適化ではありません。同じ情報ずれなら通常の誤報でも改ざんでも計算結果は同じです。[結論と限界](docs/予備比較レポート.md)を併せて読んでください。
